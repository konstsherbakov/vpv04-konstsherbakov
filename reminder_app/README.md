# Напоминалка для Windows 11

## Запуск
```
pip install -r requirements.txt
python main.py            # или pythonw main.py — без окна консоли
python main.py --minimized
```
Без `winotify` приложение тоже работает, но показывает только popup-окна.

## Файлы
| Файл          | Назначение |
|---------------|------------|
| `db.py`       | SQLite: схема (создаётся при старте), CRUD, запросы для планировщика |
| `notifier.py` | Фоновый поток-планировщик + системные toast-уведомления Windows |
| `gui.py`      | tkinter: главное окно, диалог добавления, popup поверх всех окон |
| `main.py`     | Точка входа |

База: `reminders.db` рядом со скриптами.

## Логика статусов
- **Ожидает** — новое напоминание.
- Когда время наступает: toast Windows + окно поверх всех окон (кнопки «Готово», «Отложить», «Закрыть»).
- Если за 15 минут после срабатывания не отмечено «Готово» — **Просрочено**.
  Напоминания, пропущенные пока программа была закрыта, показываются при запуске
  с пометкой «Пропущенное» и сразу получают статус «Просрочено».
- **Готово** / **Отменено** — вручную, из списка или из popup.

## Автозапуск
Win+R → `shell:startup` → создать ярлык на
`pythonw.exe "C:\путь\к\main.py" --minimized`.
