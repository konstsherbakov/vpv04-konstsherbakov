# Менеджер паролей (CLI)

Хранит логины и пароли в SQLite3; пароли зашифрованы Fernet (библиотека `cryptography`).

## Запуск
```
pip install -r requirements.txt
python main.py                 # интерактивный режим: вход один раз, дальше вводите команды
python main.py <команда> ...   # одна команда и выход
```

При первом запуске программа попросит придумать мастер-пароль (минимум 6 символов).
Дальше без него программа не откроется: даётся 3 попытки.

## Команды
| Команда | Что делает |
|---------|------------|
| `add [название]` | добавить запись: название, логин, пароль (Enter вместо пароля — сгенерировать) |
| `get <название>` | показать логин и пароль; в интерактивном режиме заново спрашивает мастер-пароль |
| `list` | список записей: названия, логины, дата изменения (без паролей) |
| `delete <название> [-y]` | удалить запись (с подтверждением, `-y` — без него) |
| `new [название] [-l N] [--no-symbols]` | сгенерировать случайный пароль; если указано название — сохранить в новую запись или заменить пароль в существующей |

Названия не зависят от регистра: `Google` и `google` — одна запись.

## Файлы
| Файл | Назначение |
|------|------------|
| `db.py` | SQLite: создание таблиц при старте и все запросы |
| `crypto.py` | ключ `.key`, шифрование Fernet, SHA-256 мастер-пароля, генератор паролей |
| `main.py` | CLI: вход, команды, интерактивный режим |
| `passwords.db` | база (создаётся сама) |
| `.key` | ключ шифрования (создаётся при первом запуске) |

## Как хранятся данные
- `master` — одна строка: случайная соль и SHA-256 от «соль + мастер-пароль». Сам пароль нигде не хранится.
- `entries` — название, логин, пароль в виде токена Fernet, даты создания и изменения.

**Важно:** `.key` и `passwords.db` нужно хранить вместе и не выкладывать в git (они в `.gitignore`).
Без `.key` пароли не расшифровать: если файла нет, а записи в базе есть, программа остановится,
а не создаст новый ключ.
